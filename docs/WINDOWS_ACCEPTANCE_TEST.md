# Windows実機受け入れテスト

対象: kaito `0.10.0.dev0` リリース候補

この手順は、GitHub Actionsでは確認できないGUIの表示、操作感、ドラッグ&ドロップ、エクスプローラー統合をWindows実機で確認するためのものです。

## 合格条件

- 必須項目がすべてPASS
- クラッシュ、フリーズ、展開先外への書き込みがない
- パスワードが画面、ログ、エラー文に露出しない
- キャンセル後に7-Zipプロセスと一時ファイルが残らない
- アンインストール後にコンテキストメニューとインストール先が残らない

1件でも必須項目がFAILの場合、`0.10.0`へ確定しません。

## 検証対象

GitHub Actions workflow run `29173588462` の成果物を使用します。

| ファイル | SHA-256 |
|---|---|
| `kaito.exe` | `aa794a0bade4f772a4e56735837453f86ec000219b176328c9e2bdc5308aaf66` |
| `kaito-installer-0.10.0.dev0.exe` | `7ba857bd9c6f84b9bc5b1a68066a1e0f4c39781abe6e115cef216f8889fc38b3` |

インストール前に次を実行し、ハッシュが一致することを確認します。

```powershell
Get-FileHash .\kaito-installer-0.10.0.dev0.exe -Algorithm SHA256
```

## テストデータ

個人情報や業務データは使用しません。テスト専用ディレクトリを作成します。

```powershell
$Root = Join-Path $env:USERPROFILE 'Desktop\kaito 受け入れテスト'
New-Item -ItemType Directory -Path $Root -Force | Out-Null
```

最低限、以下を用意します。

- 通常ZIP
- 通常7z
- 通常RAR
- パスワード付きZIP
- パスワード付き7z
- パスワード付きRAR
- 日本語、空白、絵文字を含むファイル名
- 複数階層と空ディレクトリ
- 同名ファイルを含む展開先
- 途中キャンセルできる大きさの7zまたはZIP
- テキスト、画像、10MBを超えるプレビュー対象

## 1. インストール

- [ ] インストーラーが起動する
- [ ] ユーザー単位で管理者権限なしにインストールできる
- [ ] 日本語と空白を含むインストールパスを指定できる
- [ ] インストール完了後にkaitoが起動する
- [ ] タイトルバーに`0.10.0.dev0`が表示される
- [ ] SmartScreen警告の有無を記録する
- [ ] Windowsの「インストールされているアプリ」にkaitoが表示される

## 2. 初回起動と表示

- [ ] ウィンドウが画面外へ出ない
- [ ] 100%、125%、150%の表示倍率で主要ボタンが欠けない
- [ ] 最小ウィンドウサイズでも操作可能
- [ ] 日本語が文字化けしない
- [ ] 初期画面のドラッグ&ドロップ案内が理解できる
- [ ] 設定画面が開閉できる

## 3. 通常アーカイブ

ZIP、7z、RARそれぞれで確認します。

- [ ] ドラッグ&ドロップで読み込める
- [ ] 「開く」ボタンから読み込める
- [ ] ファイル名、サイズ、圧縮後サイズ、更新日時が妥当に表示される
- [ ] 展開先の初期値がアーカイブの親ディレクトリになる
- [ ] 展開後に余分な`archive/archive`階層ができない
- [ ] 日本語、空白、絵文字を含む名前が保持される
- [ ] 空ディレクトリが保持される
- [ ] 展開内容が元データと一致する
- [ ] RAR作成の選択肢が表示されない

## 4. 複数アーカイブのキュー

- [ ] 複数のZIP、7z、RARを同時にドロップできる
- [ ] 全件がキューへ登録される
- [ ] 順番に処理される
- [ ] 1件失敗しても他のキュー状態が壊れない
- [ ] 各アーカイブのパスワードが他アーカイブへ流用されない
- [ ] 完了件数と残件数の表示が一致する

## 5. パスワード付きアーカイブ

ZIP、7z、RARそれぞれで確認します。

- [ ] パスワード未入力時に入力を求められる
- [ ] 間違ったパスワードで明示的に失敗する
- [ ] 間違ったパスワードがキャッシュされない
- [ ] 正しいパスワードを再入力すると成功する
- [ ] パスワードがエラーダイアログに表示されない
- [ ] パスワードがアプリのログや出力ファイルに残らない
- [ ] 別アーカイブでは再入力が必要になる

## 6. 圧縮

- [ ] 単一ファイルをZIPへ圧縮できる
- [ ] ディレクトリをZIPへ圧縮できる
- [ ] 単一ファイルを7zへ圧縮できる
- [ ] ディレクトリを7zへ圧縮できる
- [ ] 暗号化ZIPが正しいパスワードで開ける
- [ ] 暗号化7zが正しいパスワードで開ける
- [ ] 入力ファイルと出力アーカイブが同じ場所でも自己包含しない
- [ ] 既存出力と衝突した場合に無警告で上書きしない
- [ ] RARを出力形式として選択できない

## 7. キャンセル

大きなアーカイブの圧縮と展開でそれぞれ確認します。

- [ ] 処理中だけキャンセルボタンが表示される
- [ ] キャンセル操作に反応する
- [ ] GUIがフリーズしない
- [ ] キャンセル後に操作可能状態へ戻る
- [ ] タスクマネージャーに`7z.exe`が残らない
- [ ] 不完全な出力を成功扱いしない
- [ ] 一時ファイルとステージングディレクトリが残らない
- [ ] アプリ終了操作とキャンセルが競合しない

## 8. 上書きと衝突

- [ ] 展開先に同名ファイルがある場合の動作が明確
- [ ] 既存ファイルが意図せず破壊されない
- [ ] `FILE.txt`と`file.txt`を含むアーカイブが安全に拒否される
- [ ] 同一内部パスを複数回持つアーカイブが安全に拒否される
- [ ] Windows予約名やADSを含むアーカイブが安全に拒否される

## 9. プレビュー

- [ ] テキストファイルを選択すると内容が表示される
- [ ] 画像ファイルを選択すると画像が表示される
- [ ] 選択を素早く切り替えても古いプレビューが上書きしない
- [ ] 大きすぎるファイルを無制限に読み込まない
- [ ] 未対応形式でクラッシュしない
- [ ] RARまたは7zのプレビューでアーカイブ全体を展開しない

## 10. 設定

- [ ] 設定変更を保存できる
- [ ] 再起動後も設定が維持される
- [ ] 安全上限を厳しくすると該当アーカイブが拒否される
- [ ] 不正な設定JSONでも起動でき、既定値へ戻る
- [ ] 「完了後にフォルダを開く」が機能する
- [ ] 「完了後にアプリを閉じる」が機能する

## 11. 最近使ったファイル

- [ ] 長いパスが表示上短縮される
- [ ] 短縮表示を選択しても実際の完全パスが開く
- [ ] 存在しない履歴を選択した場合にクラッシュしない
- [ ] 履歴上限が守られる

## 12. エクスプローラー統合

- [ ] ZIPの右クリックに「kaitoで解凍」が表示される
- [ ] 7zの右クリックに「kaitoで解凍」が表示される
- [ ] RARの右クリックに「kaitoで解凍」が表示される
- [ ] 未対応拡張子に解凍メニューが表示されない
- [ ] ファイルの右クリックに「kaitoで圧縮」が表示される
- [ ] ディレクトリの右クリックに「kaitoで圧縮」が表示される
- [ ] 日本語と空白を含むパスを右クリックから渡せる

## 13. 終了処理

- [ ] 待機中に閉じられる
- [ ] 処理中に閉じると確認される
- [ ] キャンセル後にワーカー終了を待って閉じる
- [ ] 終了後にPython、kaito、7zプロセスが残らない
- [ ] 終了後に一時ディレクトリが残らない

## 14. アンインストール

- [ ] アンインストーラーが起動する
- [ ] サイレントでなく通常操作でも完了する
- [ ] インストール先が削除される
- [ ] 右クリックメニューがすべて削除される
- [ ] システムに別途入っている7-Zipへ影響しない
- [ ] 他アプリのレジストリへ影響しない
- [ ] ユーザー設定を残すか削除するかが仕様どおり
