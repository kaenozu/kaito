# 概要

kaito はドラッグ&ドロップ対応の解凍GUIです。ZIP は標準 zipfile、RAR / 7z は patool 経由で処理します。バッチ解凍（キュー）、パスワード保護ZIP、テキスト/画像プレビュー、ダークモード、Windows コンテキストメニュー統合、圧縮機能（ZIP/RAR/7z）を備えています。

主な機能

  • ZIP / RAR / 7z に対応（RAR/7z は patool 経由）
  • ドラッグ＆ドロップ、複数ファイル同時ドロップ
  • パスワード保護アーカイブ対応（ZIP）
  • バッチ解凍（キューに追加して一括実行・キャンセル可）
  • ファイル内容プレビュー（テキスト・画像）
  • ダークモード切替（System / Light / Dark）
  • 設定永続化・最近使ったファイル
  • 圧縮機能 + Windows 右クリックメニュー登録

依存パッケージ

customtkinter >= 5.2.2
patool       >= 4.0.5
pillow       >= 12.2.0
platformdirs >= 4.10.0
tkinterdnd2  >= 0.4.4.1

使い方

# GUIを起動
uv run kaito
# ファイルを指定して起動
uv run kaito path/to/archive.zip
# 右クリックメニュー登録/削除
uv run kaito --install-context-menu
uv run kaito --uninstall-context-menu
